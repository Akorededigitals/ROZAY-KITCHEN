# 🚀 Deploying Rozay Kitchen on Truehost (Step-by-Step Guide)

This guide walks you through deploying the **Rozay Kitchen** website to **Truehost** (cPanel / Shared Hosting / Node.js App Selector / Cloud VPS).

---

## 📋 Pre-Deployment Summary

The project is pre-configured with Truehost-ready production files:
1. **`.htaccess`**: Handles SPA client routing (e.g. `/track`, `/admin`, `/product/1`), automatic HTTPS redirect, GZIP/Brotli compression for fast Nigerian mobile loading, security headers, and asset caching.
2. **`robots.txt` & `sitemap.xml`**: Pre-configured for Google Search Console indexation.
3. **`dist/`**: The complete production bundle generated by `npm run build`.

---

## ⚡ Option 1: Fast cPanel File Manager Deployment (Recommended)

This is the standard and fastest method for Truehost Shared Hosting / WordPress Hosting / Web Hosting plans.

### Step 1: Build the Project
1. Run the production build command:
   ```bash
   npm run build
   ```
2. This creates a ready-to-deploy `dist/` directory containing `index.html`, `.htaccess`, `robots.txt`, `sitemap.xml`, `assets/`, and `images/`.

### Step 2: Compress the `dist` Folder
1. Open the `dist` folder on your computer.
2. Select all files inside `dist` (`index.html`, `.htaccess`, `assets`, `images`, `robots.txt`, `sitemap.xml`, etc.).
3. Right-click and choose **Compress to ZIP** (e.g. `rozaykitchen-dist.zip`).
   > *Note: Make sure `.htaccess` is included in the zip file.*

### Step 3: Upload to Truehost cPanel
1. Log in to your **Truehost Client Area** -> Click **Services** -> **cPanel**.
2. Under **Files**, click **File Manager**.
3. In File Manager settings (top right gear icon), check **"Show Hidden Files (dotfiles)"** and click Save.
4. Navigate to the **`public_html`** folder (or your subdomain folder like `public_html/shop`).
5. If there is a default `index.html` or placeholder file, delete it.
6. Click **Upload** in the top menu and select your `rozaykitchen-dist.zip`.
7. Once uploaded (100% green bar), go back to File Manager, right-click the zip file, and click **Extract**.
8. Verify that `index.html` and `.htaccess` are directly inside `public_html`.

---

## 🖥️ Option 2: Truehost cPanel "Setup Node.js App" (For Full-Stack Server)

If you want to run the optional Express AI backend on Truehost:

1. In Truehost cPanel, search for **"Setup Node.js App"** (CloudLinux / Phusion Passenger).
2. Click **Create Application**:
   - **Node.js version**: Choose `v20.x` or `v22.x`
   - **Application mode**: `Production`
   - **Application root**: `rozay-server` (or `public_html`)
   - **Application URL**: Select your domain (`rozaykitchen.com`)
   - **Application startup file**: `dist/server.cjs`
3. Upload project files, run `npm install --production`, and click **Start Application**.

---

## 🔒 Step 4: Activate Free SSL on Truehost (HTTPS)

1. In Truehost cPanel, search for **"SSL/TLS Status"** or **"Let's Encrypt SSL"**.
2. Select your domain (`rozaykitchen.com` and `www.rozaykitchen.com`).
3. Click **"Run AutoSSL"** or **"Issue Let's Encrypt Certificate"**.
4. Once completed, your site will automatically load securely with a padlock (the `.htaccess` file will redirect all visitors to `https://`).

---

## 🌐 Step 5: Domain DNS Settings on Truehost

If you registered your domain with Truehost or external registrar:
- **Truehost Nameservers**:
  - `ns1.truehost.cloud`
  - `ns2.truehost.cloud`
- Or point the **A Record** to your Truehost Server IP address:
  - Host: `@` -> Points to: `[Your Truehost Server IP]`
  - Host: `www` -> Points to: `[Your Truehost Server IP]`
